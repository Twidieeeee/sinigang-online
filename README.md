# Sinigang Online — 10 Player Custom Rules

Maximum players: 10. Winning Kanin: 7. Kakain Na! threshold: 20.

Cards: Baboy 5 each; if mixed with Hipon, -3 per Baboy. Hipon 4 each; if mixed with Baboy, -2 per Hipon. Gabi multiplies by 2 per card. Sampalok 1=6, 2=6 total, 3=0. Kangkong 3 each. Kamatis 2 each. Sili -3 each.

Family: Tatay eats Baboy; Nanay eats Kangkong; Ate eats Kamatis; Kuya eats Sampalok; Bunso eats Hipon; Lolo't Lola eats Gabi; Marites -3 with Baboy, +3 without Baboy.

The server sends only each player's own hand to that player's socket.
